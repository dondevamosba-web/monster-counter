# Monster Counter

A simple, private counter app for tracking monster kills, epic drops, and coins.

**Live:** https://dondevamos.github.io/monster-counter/

## Features
- Large TAP button to increment monster kills
- Epic Drops counter (+/−)
- Coins counter (+/−)
- Local storage persistence (works offline)
- Mobile-first PWA design
- Add to home screen on iOS/Android

## Deploy with GitHub Pages
This site is automatically deployed on every push to GitHub Pages.

No backend or database required. Everything is stored locally on your device.
